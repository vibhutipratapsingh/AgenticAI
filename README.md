# Agentic AI: Zero to Production
### A Complete Beginner → Advanced Course on Building Real AI Agents

This repository is a self-contained, self-study curriculum on **Agentic AI** — systems built on Large Language Models (LLMs) that can reason, plan, use tools, remember, and act autonomously toward a goal.

No prior AI knowledge is assumed. Basic programming familiarity helps but every concept is explained from first principles, with analogies, diagrams, and practical examples before any code.
